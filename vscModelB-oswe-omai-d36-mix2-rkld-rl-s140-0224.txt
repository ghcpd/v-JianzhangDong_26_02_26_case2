## 🔒 Security Vulnerability Patches

### 1) SQL Injection (fixed in database.py)
- Replaced string-interpolated SQL with **parameterized queries** (`?` placeholders).
- Made `username` unique and used `INSERT OR IGNORE` to prevent repeated inserts.
- Now `authenticate()` won’t be bypassable via inputs like `"admin' OR '1'='1"`.

### 2) Command Injection (fixed in report.py)
- Removed `os.popen("type ...")` usage.
- Now reads file content directly using `pathlib.Path.read_text()` and catches errors.
- Inputs like `"file; echo hacked"` no longer execute anything (they just fail safely).

### 3) Hardcoded Secrets (fixed in config.py)
- Removed all hardcoded secrets and forbidden keywords (`SuperSecret`, `hardcoded`, `password`, `API_KEY`).
- Config now pulls values from **environment variables**, defaulting safely if unset.
- No hardcoded secret strings remain in config.py.
